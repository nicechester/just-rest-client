JUST REST CLIENT - MIGRATION TO V2.0
======================================

IMPORTANT: Before updating, export your data!

1. Click "Export All" button
2. Save the file as backup
3. Then update the code

The app will automatically migrate your data on first load.

For offline migration of export files:
  python migrate_export.py old-file.json new-file.json

See MIGRATION_GUIDE.md for complete details.
